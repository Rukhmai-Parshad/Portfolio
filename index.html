About Me

Backend developer focused on building secure, containerized Django REST APIs for production.

I build backend systems the way they're meant to be built for production, not just to run once and work. Working primarily in Python and Django, I structure REST APIs around Django REST Framework, keeping the data-access layer clean through the Django ORM instead of raw SQL, so the codebase stays consistent and maintainable as it grows. PostgreSQL, MySQL, MS SQL Server, and SQLite handle persistence depending on the project, with pagination and filtering enforced at the API layer. Every endpoint I ship comes with JWT-based authentication and permission-based access control, because security isn't something I bolt on afterward — and every API is documented with Swagger/OpenAPI via drf-spectacular so it's usable without reading the source. I containerize services with Docker and deploy them as live systems on Render and Vercel, rather than leaving them as local demos. Outside the API layer, I also work with Pandas to turn raw PDFs, Excel sheets, and CSVs into clean, structured data — automating reporting and reconciliation work that would otherwise be done by hand.
