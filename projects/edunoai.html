Overview

EdunoAI is a responsive, multi-page educational website built with HTML5 and CSS3 to practice responsive layouts, semantic markup, and consistent, reusable styling across a full site — home, about, courses, blog, and contact pages, plus individual blog articles.

Features

  • Multi-page architecture: home, about, courses, blog, individual blog articles, and contact.
  • Responsive layout and navigation across breakpoints using semantic HTML5 and CSS3.
  • Reusable styling and consistent UI design across every page.
  • Image-based content sections built with a clean, organized project structure.

Tech Stack

  • HTML5
  • CSS3

Architecture

API Highlights

  • 7 static pages including 6 individual blog articles
  • Fully responsive navigation and layout
  • Reusable CSS styling across all pages

Deployment

Deployed as a static site, live at hireanintern.in.

Challenges

  • Structuring a multi-page site (7+ HTML pages) with consistent navigation and styling without a framework.
  • Building responsive layouts that hold up across breakpoints using only HTML5 and CSS3.
  • Keeping styling reusable and consistent across every page instead of duplicating rules.

Learnings

  • Strengthened frontend fundamentals: semantic HTML, responsive design, and CSS layout techniques.
  • Practiced multi-page website architecture and consistent navigation design.
  • Hands-on experience with typography, UI design principles, and clean project organization.
